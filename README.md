🧠 Customer Behavior Analysis

This project focuses on analyzing customer purchasing behavior using a real-world dataset. It aims to uncover insights into buying patterns, spending habits, and customer segmentation through data analysis and visualization.

📊 Project Overview

The Customer Behavior Analysis project uses Python, SQL, and Power BI to perform end-to-end data analytics.
It involves:

  Cleaning and wrangling raw customer data.
  
  Executing SQL queries for data exploration and analysis.
  
  Building an interactive Power BI dashboard for visual insights.

🧰 Tools & Technologies

  Python (Pandas, NumPy, Matplotlib, Seaborn)
  
  Jupyter Notebook
  
  MySQL / SQL Workbench

Power BI

⚙️ Steps Involved

1. Data Wrangling (Jupyter Notebook):
  
    Loaded and cleaned the dataset using Pandas.
    
    Handled missing values and performed feature selection.
    
    Conducted exploratory data analysis (EDA) to identify trends.

2. Database Operations (SQL):

    Created database and tables in MySQL.
    
    Wrote SQL queries for filtering, grouping, and aggregating data.
    
    Dashboard Development (Power BI):
    
    Connected processed data to Power BI.
    
    Designed an interactive dashboard showcasing customer insights.
    
    Visualized key metrics like purchase frequency, spending distribution, and customer demographics.

📈 Key Insights

  Identified top customers and high-revenue segments.
  
  Highlighted key factors influencing purchasing decisions.
  
  Discovered trends in buying frequency and regional preferences.
